# cinco-futuros

Kit para você se preparar para os **5 futuros da IA**: extinção total, zoológico humano, governo mundial da IA, paraíso feito pela IA e utopia verdadeira.

Você copia o kit para a sua pasta, e o seu agente (Claude Code ou Codex) faz três coisas:

- monta a sua **agenda de preparação**;
- **monitora toda semana** os sinais de qual futuro está chegando mais perto;
- **reorganiza a agenda** quando um sinal passa do limite.
